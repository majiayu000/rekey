# Support

Rekey `2.0.0-alpha.1` is an experimental public Alpha with best-effort
community support. There is no SLA, 24x7 response, guaranteed fix time,
commercial support, or enterprise escalation path.

Before opening an issue, verify the supported platform in
`docs/alpha-scope.md`, read `docs/operations-runbook.md`, and reproduce with a
current release artifact. Include version output, OS/architecture, exact error
code, sanitized logs, and minimal steps. Never post passwords, credentials,
recovery keys, capability tokens, private repository data, or raw vault files.

Use GitHub Issues for usage defects and GitHub Security Advisories for private
vulnerability reports. Feature requests outside the frozen v2 boundaries need
a separate proposal and security model.
