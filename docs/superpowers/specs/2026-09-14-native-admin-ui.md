# 本机 macOS 管理界面

用户已接受 `outputs/rekey-ui-concept-20260914/credential-manager-v1.png` 的浅色中文布局，并授权实现。此源码切片增加 SwiftUI 管理客户端，不恢复旧版 Web Vault / Dashboard，也不增加 HTTP 监听。

## 实现边界

- 本地构建 `Rekey.app`，随包携带同一次构建的 `rekey` / `rekeyd`。通过 Foundation Process 的固定参数数组调用 CLI，不运行 shell、不接受自定义命令。
- 所有密码、恢复证明、新凭证只通过 SecureField 和匿名 stdin pipe；不放 argv、env、日志、剪贴板、UserDefaults 或临时文件。类型化 profile 由用户选择现有私有文件，CLI 继续检查权限。
- 不打开 SQLite，不读取/导出已有凭证，不修改 Agent API。敏感修改每次要求证明；输入完成或取消后清除界面字段。Swift 字符串不提供可验证清零保证，仍属于可信 G1 Admin 进程。
- 只持久化非秘密的本机状态目录。短期 capability 与恢复密钥仅在当前结果窗口中出现，允许用户显式保存为新建的 0600 文件；关闭后不提供历史查看。
- 提供凭证列表/详情/添加/轮换/撤销、Action 列表与定义文件导入/更新/禁用、授权创建/撤销、签名策略导入、生效状态、审批 pending/get 导出、审计筛选/分页/导出、备份/恢复、密码/恢复密钥修改。
- 初始化、恢复只针对用户选择的目录，非空/旧格式拒绝仍由 CLI 决定。UI 不生成解锁密码。首次打开未初始化的目录时自动展示密码设置，创建成功后自动启动服务；已有保险库通过显式按钮启动服务；关闭 UI 不终止 Broker，Broker 继续遵守 idle lock。界面失焦重新获取状态，服务断开/锁定时清除显示缓存。
- 不实现 GUI 内自动签名、任意执行终端、活动会话全量列表、团队管理、云功能、Windows、macOS 强隔离。

## 验证

构建原生 app；使用临时保险库测试真实 CLI 启动、初始化、错误密码、添加/轮换/撤销、锁定和审计；敏感输入不在子进程 argv；检查界面空状态、搜索、详情和真实数据。Rust workspace check 及现有相关测试保持通过。UI 代码的定向检查和交互验收不等于独立人工安全审计。此切片不自动发布或合并。

## 2026-09-15 用户修订：个人密钥管理

用户明确要求管理员可以查看、复制原有密钥；解锁后添加 API Key 不再逐次输入保险库密码。该要求覆盖此前“Admin 也不可读取凭证”的产品限制，但不授予 Agent 读取密钥的能力。此节为当前实施契约，覆盖上文与其冲突的旧限制；人工安全审阅仍需独立完成。

最小交互：
- 默认添加入口为“添加 API Key”，字段为名称、API Key；其他凭证类型为次级入口。
- 例如 GLM：名称“智谱 · 个人开发”，API Key 字段填原始密钥，不填变量名、Bearer 或 JSON。只保存不要求创建 Action 或签名策略。
- 当前界面完成解锁后，可连续添加、查看和复制。添加表单不再混入保险库密码。
- 详情默认掩码，显式点击显示；切换条目、失焦、锁定、超时即隐藏并清除 UI 中的值。
- 复制必须显式点击，声明写入系统剪贴板；30 秒后仅在剪贴板仍是本应用那次写入时清理，不覆盖用户后续复制。不能宣称已清除剪贴板历史工具保存的副本。

最小授权实现：
- 按用户最新要求，管理会话有效期与默认空闲自动锁定时间均为 7 天；手动锁定和服务重启仍立即结束解锁周期。
- 密码仍通过 stdin/IPC body 完成验证；成功后签发独立、随机的短期 Admin 会话凭证，只存在 UI 和 Authority 的内存。
- 该会话仅允许日常凭证添加、当前值查看/复制。改主密码、恢复密钥、策略和授权等高影响操作继续使用已有 step-up。
- 会话与本次解锁周期绑定，锁定、故障或过期后失效；退出 UI 丢弃本地凭证，服务端凭证最迟在到期时失效；不跨重启持久化、不缓存主密码、不使用可由调用方声称的“已解锁”布尔值作为认证。
- Agent socket 和 Agent capability 不接受 Admin 明文读取；管理员读取响应的秘密只在 body 中传输，不写 JSON metadata、日志或审计内容。
- 查看先验证授权及记录审计，再解密。失败关闭，不返回半条秘密；读取成功/失败审计只记录对象和结果，不记录值。
- 默认展示 opaque-token 当前有效值。被轮换的历史版本不在此范围；撤销凭证不因此恢复可用。
- 保留 G1 边界：与 UI 同用户且能读取其进程内存的恶意程序不在此机制的完全防护范围内。

验证与交付：
- 正确 Admin 会话可以读取原值；错误、过期、锁定、其他解锁周期及 Agent capability 均拒绝。
- 保存后读取一致；审计失败不泄露值；日志/审计无测试 canary。
- 实机连续添加 GLM 等多把合成 Key，不重复输入密码；显示/隐藏、复制超时、锁定清除逐项验收。
- 修订旧的“任何 secret-read 都禁止”机械检查，使其针对 Agent 接口，并增加 Agent/Admin 隔离测试；不直接删除测试或弱化 Agent 安全边界。
- 按仓库 SEC-11，秘密读取及认证实现须经人工审阅后部署。本节是审阅材料，不是完成证明。

审查补充：后台轮询只读取不续期的状态；日常保存及读取使用已有 Admin 截止时间，过期请求在提交或解密前拒绝。拒绝与失败读取记录不含秘密的审计结果。失效管理会话清除本地凭证，所有添加入口均经过会话检查。备份客户端等待时间覆盖 Broker 的 300 秒响应窗口。切换工作目录后，服务进程归属于其启动目录。
