# 本机 macOS 管理界面

用户已接受 `outputs/rekey-ui-concept-20260914/credential-manager-v1.png` 的浅色中文布局，并授权实现。此源码切片增加 SwiftUI 管理客户端，不恢复旧版 Web Vault / Dashboard，也不增加 HTTP 监听。

## 实现边界

- 本地构建 `Rekey.app`，随包携带同一次构建的 `rekey` / `rekeyd`。通过 Foundation Process 的固定参数数组调用 CLI，不运行 shell、不接受自定义命令。
- 所有密码、恢复证明、新凭证只通过 SecureField 和匿名 stdin pipe；不放 argv、env、日志、剪贴板、UserDefaults 或临时文件。类型化 profile 由用户选择现有私有文件，CLI 继续检查权限。
- 不打开 SQLite，不读取/导出已有凭证，不修改 Agent API。敏感修改每次要求证明；输入完成或取消后清除界面字段。Swift 字符串不提供可验证清零保证，仍属于可信 G1 Admin 进程。
- 只持久化非秘密的本机状态目录。短期 capability 与恢复密钥仅在当前结果窗口中出现，允许用户显式保存为新建的 0600 文件；关闭后不提供历史查看。
- 提供凭证列表/详情/添加/轮换/撤销、Action 列表与定义文件导入/更新/禁用、授权创建/撤销、签名策略导入、生效状态、审批 pending/get 导出、审计筛选/分页/导出、备份/恢复、密码/恢复密钥修改。
- 初始化、恢复只针对用户选择的目录，非空/旧格式拒绝仍由 CLI 决定。UI 不生成解锁密码。首次打开未初始化的目录时自动展示密码设置，创建成功后自动启动服务；已有保险库通过显式按钮启动服务；关闭 UI 不终止 Broker，Broker 继续遵守 idle lock。界面失焦重新获取状态，服务断开/锁定时清除显示缓存。
- 不实现 GUI 内自动签名、任意执行终端、活动会话全量列表、团队管理、云功能、Windows、macOS 强隔离。
