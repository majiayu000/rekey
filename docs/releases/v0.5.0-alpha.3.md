# Rekey 0.5.0-alpha.3 发布说明

这是 0.5 预发布版的打包重发。发布验收改用静态 HTTPS 资源，继续通过签署的 Connection 执行真实读取，并检查未经审批的写操作仍被拦截。应用行为、保险库格式 vault27 和策略格式 policy8 与 alpha.2 一致。alpha.2 的标签和草稿资产保留。

## 升级和安装

- 已使用 0.5 的 vault27 保险库可继续使用。
- 从 0.4 及更早版本升级时，保留原保险库、规则和备份，在新目录初始化 0.5 保险库。旧格式无法在 0.5 中打开。
- macOS 14 及以上的 Apple Silicon 使用 Developer ID 签名并经 Apple 公证的安装包。Linux 资产面向 Ubuntu 24.04 x86_64。
- 下载与 SHA-256 校验文件以 [GitHub Releases](https://github.com/majiayu000/rekey/releases) 为准。操作步骤见[安装指南](https://github.com/majiayu000/rekey/blob/v0.5.0-alpha.3/docs/installation.md)。

0.5 的功能和限制见 [alpha.2 发布说明](https://github.com/majiayu000/rekey/blob/v0.5.0-alpha.2/docs/releases/v0.5.0-alpha.2.md)。
