# Rekey 3.0.0-alpha.1 — 未发布候选

本说明适用于旧格式/旧 schema 的升级：旧库与旧备份不迁移、不双读、不回填。
保留匹配的旧二进制、状态与备份，在新空目录创建当前保险库并重新登记。
当前 vault25 / policy6 仍是预 GA 格式，尚未最终冻结；相同预发布格式号不是互读承诺。
这不是 `3.0.0` GA，不代表已经创建 tag、上传产物或完成公开发布。

## 候选内容

- 每次敏感管理操作的新证明、Presence 七天授权、签名前 peer 校验与内存清理。
- 认证代数与外部 high-water、疑似回滚锁定、明确确认及两步离线恢复。
- 个人/团队固定信任模式、Provider 模板、完整策略差异与逐能力规则选择。
- 本机一次审批、外部 Ed25519 审批、Agent 允许路径零交互。
- 签名 Profile、owner-bound run、MCP、SDK loopback gateway、共享预算与 raw SSE。
- App 引导、Activity、保守保护等级、只读旧格式指引、短 Key 提醒。
- 签名 pkg / release-local cask 生成、systemd user unit；企业路径默认关闭。

## 安装与数据处理

macOS 仅 pkg 为主路径；`rekey.rb` 根据该真实 pkg 的 hash 生成并随同一 release 上传，
没有外部 tap 已发布的承诺。Linux 为 tar.gz + 用户服务。
见[安装指南](../installation.md)、[使用指南](../user-guide.md)与[明确恢复流程](../operations-runbook.md#routine-backup-and-restore-drill)。

卸载只处理 App/receipt/安装链接或已安装用户 unit，不删 vault、备份、Keychain 或代数锚。
GA 后同一主版本的次/补丁版本不得改变持久格式；破坏性变化必须进入新主版本。
