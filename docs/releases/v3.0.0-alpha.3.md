# Rekey 3.0.0-alpha.3

首个 v3 alpha：固定动作与参数授权，Agent 使用短期 capability，接触不到上游 Key。
这不是 GA，不宣称完整 L1 / L2。公开状态以 [GitHub release](https://github.com/majiayu000/rekey/releases/tag/v3.0.0-alpha.3) 和对应 workflow 结果为准。

alpha.1 与 alpha.2 的 tag 均保持不变，尚未公开发布。alpha.1 的 Swift 编译超时已修复；alpha.2 通过 App/pkg 签名公证和安装后的 P0，但共享验收脚本误要求归档专用 Python 工具。
本版将这些检查移回 tar.gz 入口，保留 macOS 原生行为及服务验收，并直接使用安装 bundle 内的 daemon，保留其 profile；不改变产品或安全语义。
[alpha.2 失败验收](https://github.com/majiayu000/rekey/actions/runs/37248064583)保留为证据。

## 本次内容

- 新证明保护敏感管理操作、Presence 快捷认证、发送前 daemon 签名校验。
- Secure Enclave 个人策略签名、Provider 模板、完整授权差异审阅。
- 参数绑定的一次本机审批、签名 Profile、owner 生命周期及 MCP 接入。
- loopback SDK 网关、raw SSE、持久用量、Activity 和保守预算结算。
- 外部 high-water 与认证代数、疑似回滚锁定、明确确认及离线恢复。
- 签名、公证 pkg、由最终 pkg 生成的 cask、Linux tar.gz 与用户服务。
- 默认 feature 为空；企业能力在 lab，relay 的 bin / test 均需 lab，没有默认 lib。

流式非 200 错误在有界遮蔽和终态审计后保留原 HTTP 状态、正文及允许的重试头。
DoH 默认关闭，只在明确配置 REKEY_DOH_URL 后启用；不放宽公网与 TLS 检查。
HTTP 阻塞写入有期限。同次策略激活复用既有固定十秒认证 context，结束即失效。

发布前独立 agent 安全核心审查发现并修复两项问题：Anthropic 交错文本块可能绕过
按事件顺序的秘密检测；首 chunk 前的安全失败会丢失原错误码与不可重试属性。
修复采用有界、按 SDK 内容顺序的文本投影和现有错误事件，不改变持久格式。
[审查记录](../evidence/v3-security-core-review-2026-10-05.md)包含合成复现与检查边界。
这是代码审查，不是外部人工安全审计。

另修复 Profile 创建审计提交后失败时遗漏撤销审计的问题：先撤销内存会话，
再持久记录撤销，保留原错误；撤销审计失败则故障关闭。
修正 Profile 映射按主体分组；macOS 隔离 helper 的 Ctrl-C 复用既有终止与清理路径，
已用真实子进程验证直接 Agent 回收和私有临时目录清除。

日预算是按已结算用量拒绝后续请求的软限制；在途输出可能超额。
Agent 执行不推进回滚代数，同代数合法旧快照可重置随后用量；不宣称防本机状态
回滚的费用封顶。完整历史账本在每次准入/结算时认证，成本随历史增长，未做汇总压缩。
