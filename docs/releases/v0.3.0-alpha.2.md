# Rekey 0.3.0-alpha.2

修复已发布 alpha.1 中有界大响应的 SSE 失败，并整理定位与信任模型说明。
[公开状态与下载](https://github.com/majiayu000/rekey/releases/tag/v0.3.0-alpha.2)
及完整 release workflow 为准；本地测试或创建 tag 不代表发布完成。

## 本次修复

- 回收已检查并发出的 raw SSE 前缀及工具元数据尾，允许上限内的长文本和工具响应完成；
  累计正文上限、有限反射检查、EOF 和持久用量结算仍约束成功路径。
- 在有界分块处让出执行权；发送前撤销检查覆盖 future 创建和首次 poll，保留取消、超时和审计错误契约。
- 优化现有认证用量账本处理；保持完整历史认证，不增加持久状态，成本仍随账本增长。
- 补齐 API 凭据执行器定位和 L1-dev 边界；竞品档案分别记录已发布基线、修复候选和证据等级。

vault / backup **25**、policy snapshot **6** 与现有签名授权保持不变。
不加入第三方密码管理器、SSH、mTLS、团队协作或高可用；不增加迁移或旧格式读取。

这是有界组件测量，不代表真实 provider 或发布包验收；并发上限仍为 4。

default/lab all-targets 编译、严格 Clippy 和机械契约通过；版本变更仍须完整 PR CI。
