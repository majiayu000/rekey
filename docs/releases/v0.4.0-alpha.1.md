## 新调用模型

Agent 按正常方式启动，通过 CLI、MCP、本机 HTTP 或 SSH agent 调用 Rekey。Rekey 保存密钥并返回调用结果；本机调用不需要授权令牌，权限来自用户签署的规则。HTTP 使用公开 `rekey` 占位头作为请求标记。

- Connection 绑定一个密钥、固定 host 和路径/读写规则；deny 优先，调用方限制只能收紧。默认读允许、写审批，具体危险路径可拒绝。
- 新增 `list`、`describe`、`call`、`http`、dry-run、访问请求及等待；错误带下一步提示。审批可批准一次或同规则时间窗，最长 8 小时，锁定和改策略后失效。
- `connect` 写入 Claude Code / Codex / Cursor MCP 配置及项目说明，可选 pre-commit 扫描和 SSH `IdentityAgent` 配置；不写密钥或令牌。
- `.env` 导入由 App 确认；CLI 只显示变量名。可选原子改写保留私有备份。`scan` 只返回完整秘密及支持变体的位置。
- SSH key 与 host 规则签名，App 支持生成、公钥展示、host/git 签名编辑与完整草稿签署，私钥不导出；git smart HTTP 使用固定 GitHub 预设与读写端点。
- OAuth 提供 Google、GitHub、Slack、Notion 的有限操作预设，token 托管在 Rekey；使用用户自己的 client。
- T1 提供 AWS AssumeRole、EKS、GitHub App 临时凭据，必须逐个签署目标/权限/TTL 后开启。**Agent 进程会收到临时凭据**，根密钥保留在 Rekey。

## 不兼容变更

vault/backup 格式升级为 **26**，policy 为 **7**，HTTP / SSH / T1 完整记录都进入签名快照。0.3 的 vault25、policy6 和旧备份不兼容，没有迁移、回填或旧 reader。请保留旧版本及其目录，在新目录重建 0.4 保险库与规则；不要让新旧二进制交替操作同一目录。

默认个人入口移除 `rekey run`、Agent Profile 和本机 capability。旧启动器、机构控制面与相关脚本作为 `--features lab` 企业储备保留；lab 编译/语法检查不宣称旧 runtime 验收通过。
