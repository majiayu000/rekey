# Rekey 0.5.0-alpha.1 候选发布说明

这是 0.5.0-alpha.1 的发布准备稿；是否已发布及可下载资产以 [GitHub Releases](https://github.com/majiayu000/rekey/releases) 为准。Agent 通过 CLI、MCP、本机 HTTP 或 SSH agent 按签名规则调用 Rekey，通常只收到调用结果；响应遮蔽覆盖密钥原值和支持的可逆编码，不覆盖任意编码、哈希或隐蔽信道。显式开启的 AWS、EKS、GitHub App 临时凭据入口会向 Agent 返回短期凭据。

## 升级前必读

**需要新建保险库。** 0.5 的数据格式（vault27 / policy8）与 0.4（vault26 / policy7）不兼容，0.4 的保险库、规则和备份无法直接打开，不提供迁移。

1. 在 0.4 的 Rekey.app 里关闭登录启动（如已启用），以新的证明停止服务并退出 App；保留原数据目录（默认 `~/.rekey`）不要删除。
2. 安装 0.5，选择一个新的空目录作为保险库，重新添加密钥。
3. 不要让新旧版本交替操作同一个目录。

## 新功能

- **添加密钥入口**：macOS 默认目录且已安装 App 时，`rekey add <预设>` 打开 App，`--app` 可明确选择此路径。App 复用已有签名密钥，软件密钥不会自动变成 Secure Enclave 密钥。无 App、自定义目录或显式 `--stdin-secrets` 使用 CLI 基础模式，输入密码和密钥后生成、签署并启用预设规则；该模式仅限测试，同用户程序可读取软件签名私钥。LLM 类密钥需要填写允许使用的模型列表。
- **记住解锁 7 天**：`rekey unlock --remember 7d`（最长 30 天）后，后台服务重启不必再输一次密码；`rekey lock --forget-remembered` 立即作废。记住解锁使用同用户可读的软件密钥，仅限可信测试环境；结合解封文件可离线解密保险库。新票据只能解锁，不能批准写操作或代替敏感操作的二次证明。旧票据不会自动降权，须重新记住或执行忘记。
- **中文错误提示**：终端显示中文原因和下一步；管道或 `REKEY_OUTPUT=json` 保持结构化错误。成功的未验证服务警告单独作为 stderr JSON 输出，不改变 stdout 结果。`init`、`serve`、`restore` 的失败仍由 `rekeyd` 输出。
- **后台请求提醒**：App 在后台时，Agent 发起访问请求或需要审批会弹出系统通知（带提示音，不含请求内容）。首次连接或首次出现待处理请求时请求一次通知权限；未授权时只显示 Dock 角标。
- **检查更新**：设置页新增“检查更新”。App 从 GitHub Releases 查找新版本（包括预发布），发现后提供“打开发布页”按钮；下载和安装由你在发布页完成，系统安装器会验证签名和公证。App 不会自行下载或安装。
- **Homebrew**：发布流程可以把 cask 提交到 `majiayu000/homebrew-rekey`。tap 上线后可用 `brew install --cask majiayu000/rekey/rekey` 安装，以 tap 仓库实际状态为准。

## 修复

- **代理软件下也能调用**：在 Clash、Surge 等 TUN 模式下，系统 DNS 会返回 198.18.0.0/15 的假地址，之前每次调用都会被拒绝。现在仅当系统 DNS 只返回这类假地址且未设置 `REKEY_DOH_URL` 时，Rekey 会改用固定 IP 的公共 DoH（223.5.5.5，然后 1.1.1.1）解析。这会把要访问的域名发给这些公共解析器；不想这样可以把 `REKEY_DOH_URL` 设为自己信任的解析器，或关闭代理的 fake-IP 模式。没有单独的关闭开关。
- **MCP 调用缺少 Content-Type**：通过 MCP 或 `rekey call` 发送 JSON 参数时，上游请求没有 `Content-Type`，GLM 等服务会返回 400。现在调用方未指定类型且请求体是 JSON 对象时默认发送 `application/json`。
- **关闭终端不再清除记住的解锁**：关闭运行 `rekeyd` 的终端会让服务按正常方式停止，不再被当成崩溃而撤销记住的桌面会话。
- **App 内添加 LLM 密钥无法启用**：添加表单会要求填写模型列表，签名后即可启用。
- 登录项在 `notFound` 状态下也会注册；从链接打开 App 时复用已有窗口。

## 安装

macOS 14 及以上、Apple Silicon：正式发布后从 Release 页下载 `rekey-v0.5.0-alpha.1-macos.pkg`，双击安装。发布门禁要求安装包由 Developer ID 签名并通过 Apple 公证；本准备稿不代表这些门禁或公开下载已完成。Linux：下载 `rekey-v0.5.0-alpha.1-x86_64-unknown-linux-gnu.tar.gz`（Ubuntu 24.04 x86_64）。校验与升级步骤见[安装指南](https://github.com/majiayu000/rekey/blob/v0.5.0-alpha.1/docs/installation.md)。

## 已知限制

- 正式设备上的 Touch ID 次数、登录项批准与重新登录、升级和卸载流程仍在人工验收中。
- 默认本机环境不防同一用户下的恶意进程滥用已经允许的规则；调用方标签不是身份认证。
- 用量预算按已结算用量执行，不是严格的费用上限。

使用方法见[用户指南](https://github.com/majiayu000/rekey/blob/v0.5.0-alpha.1/docs/user-guide.md)，备份与恢复见[运维手册](https://github.com/majiayu000/rekey/blob/v0.5.0-alpha.1/docs/operations-runbook.md)。
