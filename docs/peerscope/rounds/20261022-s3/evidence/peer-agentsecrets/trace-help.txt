$ agentsecrets help call   # HOME=<tmp>, 2026-10-22T13:03:08Z
Make a one-shot authenticated API call. Credentials are resolved
	from the OS keychain and injected into the request — they are never
	printed or exposed to your AI assistant.

	Examples:
	# Bearer token (most common)
	agentsecrets call --url https://api.stripe.com/v1/balance --bearer STRIPE_KEY

	# POST with body
	agentsecrets call --url https://api.stripe.com/v1/charges \
		--method POST --bearer STRIPE_KEY \
		--body '{"amount":1000,"currency":"usd","source":"tok_visa"}'

	# Custom header
	agentsecrets call --url https://api.example.com/data \
		--header X-API-Key=MY_KEY

	# Plain (non-secret) header. Use for Content-Type when you need one other
	# than the default: a JSON body is sent as application/json automatically.
	agentsecrets call --url https://api.example.com/data \
		--bearer MY_KEY --body '{"text":"hi"}' \
		--set-header Content-Type=application/json

Usage:
  agentsecrets call [flags]

Aliases:
  call, calls

Flags:
      --basic string             Basic auth secret key name
      --bearer string            Bearer token secret key name
      --body string              Request body (JSON string)
      --body-field stringArray   Body injection: json.path=SECRET_KEY (repeatable)
      --form-field stringArray   Form injection: field=SECRET_KEY (repeatable)
      --header stringArray       Header injection: HeaderName=SECRET_KEY (repeatable)
  -h, --help                     help for call
      --method string            HTTP method (default "GET")
      --output string            Output format: text or json (default "text")
      --query stringArray        Query injection: param=SECRET_KEY (repeatable)
      --set-header stringArray   Plain header: Name=Value, no secret lookup (repeatable)
      --token string             Agent token (optional, or reads AS_AGENT_TOKEN)
      --url string               Target API URL (required)
